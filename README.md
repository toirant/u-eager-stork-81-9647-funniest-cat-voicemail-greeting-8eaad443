Entry for the [Funniest Cat Voicemail Greeting](https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443) bounty on [make.fun](https://make.fun).

## The entry

> You've reached Miso. I'm asleep on your keyboard — leave a message after the beep. Tuna gets a callback. You don't.

115 characters, one line — a genuine voicemail greeting spoken by the cat
herself, built on the most cat-specific spot there is (asleep on the
keyboard), with Miso's own brisk, tuna-transactional attitude, and the
punch saved for the last sentence.

## Run it

```sh
node main.ts
```

It writes the greeting to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when
set). The file holds exactly the greeting above: 115 characters, one line, no
trailing newline.
